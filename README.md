# Shi Jie Lee — academic homepage

A responsive, build-free personal homepage for Shi Jie Lee (李士杰), Tsinghua University.

## Publish with GitHub Pages

1. Put `index.html`, `styles.css`, and `.nojekyll` in the repository's root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, then **main** and **/ (root)**, and save.

Use a repository named `<your-github-username>.github.io` for the address `https://<your-github-username>.github.io/`.

## Edit

Edit the profile text, email, and links directly in `index.html`. Visual styles are in `styles.css`. No packages or build step are needed.

Only confirmed personal details are included. Add degree, department, dates, research interests, publications, and a dedicated portrait when those details are available. Do not publish identity-document images.

The general academic-page structure was inspired by https://github.com/timesbye/waihangwong.github.io. This implementation and its visual assets were written independently; no source code, photographs, or biographical claims were copied from that repository.
